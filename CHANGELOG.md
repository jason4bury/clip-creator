# Changelog

All notable changes to Clip Creator can be documented in this file.

## 1.0.0

Initial GitHub release.

-   Cinematic Windows GUI
-   Random clip selection
-   MP4 `theme.mp4` output
-   One clip per movie
-   Per-movie output folders
-   Configurable clip length
-   Configurable start/end avoidance
-   Subfolder support
-   Progress percentage
-   Current movie display
-   Estimated time left
-   Created clip counter
-   FFmpeg installation check
-   Existing clip overwrite confirmation
-   Stop processing control
-   Open output folder control
-   Completion prompt
-   About dialog and credits
